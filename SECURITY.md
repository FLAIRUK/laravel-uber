# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.x | Yes |

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/FLAIRUK/laravel-uber/security/advisories/new),
or email ijeffrouk@gmail.com.

You will get a reply within a week. Once a fix is released, the advisory is
published with credit to you, unless you would rather not be named.

Never include client secrets, access tokens, webhook signing keys or rider data in a report.
